Gabungkan target MindAR

Pilih gambar sumber marker yang sama dengan gambar saat membuat targets0.mind dan targets1.mind. File keluaran berisi dua target: gambar Target 0 menjadi targetIndex: 0, lalu gambar Target 1 menjadi targetIndex: 1.

File .mind yang sudah jadi tidak dapat digabung langsung. Proses ini memerlukan gambar sumber aslinya.
